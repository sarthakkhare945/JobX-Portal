## About
- Title: `Jobx`
- Author: `Sarthak-Khare`
- Description:
  `Jobx is a modern job portal platform where individuals can share job openings, contribute opportunities, or help job seekers by posting useful information. Recruiters and professionals alike can post vacancies to help connect talent with the right opportunities. It also aims to foster a community where sharing and discovering jobs is seamless and accessible..`

`🔧 This is the frontend repository, built using React, Chakra UI, Tailwind CSS, and more. All backend functionalities (like storing job listings, user contributions, and role-based access) are handled in a private backend repository for security and performance.`

## Tech Stack (Frontend) 
⚛️ React — Core library for building UI

💅 Chakra UI — Accessible component library

🎨 Tailwind CSS — Utility-first CSS framework

🌐 Axios / Fetch — For API communication with the backend

🧪 React Router — For routing and navigation

💾 LocalStorage / Context API — For client-side state management

🎞️ Framer Motion — For sleek animations and smooth transitions
